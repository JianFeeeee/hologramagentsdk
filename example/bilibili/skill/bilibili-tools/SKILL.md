# B站内容（不含下载）

## 什么时候用

用户要**看 B站的内容与元信息**时：

| 用户说 | 用 |
|---|---|
| 「这个视频讲了什么 / 多长 / 谁做的 / 有几个分P」 | `bilibili_video` |
| 「把这个视频的字幕/文案给我」 | `bilibili_subtitles` |
| 「这个视频评论区在说什么」 | `bilibili_comments` |
| 「最近B站有什么热门」 | `bilibili_popular` |
| 「这个视频我是不是已经处理过」 | `bilibili_seen_check`（**纯本地**） |
| 「我处理过哪些视频」 | `bilibili_seen_list`（**纯本地**） |

**不要用本插件做这些**：

- **下载视频** → 用 `bili` 插件（`bili_video`，基于 yt-dlp）。本插件不下载。
- **查收藏夹/历史/稍后再看/投币点赞** → 本插件不碰账号面能力（需要登录态）。
- **番剧/直播/动态/专栏** → 编号体系不同，本插件不支持。

## 先拉起插件

```
plugin_start  name=bilibili
```

## 工具与参数

所有视频类工具的第一个参数都叫 `video`，三种写法都认：

- BV 号：`BV17x411w7KC`
- av 号：`av170001`
- 完整链接：`https://www.bilibili.com/video/BV17x411w7KC?p=2&t=10`

### `bilibili_video`（先查它）

| 参数 | 必需 | 说明 |
|---|---|---|
| `video` | ✓ | 上面三种写法之一 |

返回：标题、UP主、时长、发布时间、播放/弹幕/评论/点赞/投币/收藏/分享、
分P清单（**每个分P的 `cid`**）、简介。同时还告诉你「本地台账：已见过/未见过」。

★ **`cid` 是字幕工具的钥匙**：分P视频要拿第 2 个分P的字幕，就得把它的 `cid`
传给 `bilibili_subtitles`。别自己猜 cid，它和分P序号（P1/P2）不是一回事。

### `bilibili_subtitles`

| 参数 | 必需 | 说明 |
|---|---|---|
| `video` | ✓ | 同上 |
| `cid` | | 分P的 cid；省略则自动取第 1 个分P |
| `lang` | | 要导出的语言代码（如 `zh-CN`、`ai-zh`）；**省略则只列清单不导出** |
| `save_dir` | | 导出目录；相对路径落到插件输出目录下，`..` 越界与系统目录会被拒 |

两步走：先不带 `lang` 列清单，看到有哪些语言，再带 `lang` 导出。
清单为空时工具会解释原因（见下面的坑）。

### `bilibili_comments`

| 参数 | 默认 | 说明 |
|---|---|---|
| `video` | — | 同上 |
| `sort` | `hot` | `hot` 按热度 / `time` 按时间 |
| `pages` | 配置 `max_pages` | 翻几页，**硬上限 10** |
| `per_page` | 配置 `max_items` | 每页条数，**硬上限 100** |

返回内容包括楼中楼的**第一层**回复。深层回复不展开（要单独请求，代价大）。

### `bilibili_popular`

| 参数 | 默认 | 说明 |
|---|---|---|
| `pages` | 1 | 翻几页，硬上限 10 |
| `per_page` | 配置 `max_items` | 每页条数，硬上限 100 |

### `bilibili_seen_check` / `bilibili_seen_list` / `bilibili_seen_forget`

**纯本地，不发任何网络请求**，因此可以在没有网络/被风控时使用。

- `seen_check`：`video`。命中返回标题、UP、首次/最近见到时间、累计取回次数；
  未命中**明确说「未命中」**（不要把它当"视频不存在"）。
- `seen_list`：`limit`（默认 20，上限 200）。
- `seen_forget`：`video`。删掉一条记录。

★ 台账的语义：**本插件取回过的视频**。它不是平台收藏/历史的镜像，
所以「未命中」只意味着"我没处理过它"，不代表它不存在或用户没看过。

### `bilibili_comment_post`（写操作，默认关闭）

| 参数 | 说明 |
|---|---|
| `video` | 同上 |
| `message` | 正文，1~1000 字 |
| `root` | 回复某条主评论时填它的 `rpid` |
| `parent` | 回复楼中楼时填目标 `rpid`；省略则取 `root` |

**必须同时满足两个条件才能用**：

1. 配置 `allow_comment_post = true`（**默认 false**）
2. 配置的 Cookie 里含 `bili_jct`（csrf token）

任一不满足，工具会在本地直接拒绝并说明缺哪一项，**不会发任何请求**。
不要试图绕过：这是有意设计，示例不该是"一键刷评论"的玩具。

## 需要什么前置条件

| 能力 | 前置条件 |
|---|---|
| 视频信息 / 分P | 无（匿名可用） |
| 评论列表 | 无（匿名可用，但频率限制更严） |
| 热门流 | 无 |
| 字幕 | 匿名**通常拿不到 AI 字幕**（清单为空）。要字幕请在插件配置里填登录态 Cookie（含 `SESSDATA`） |
| 发评论 | `allow_comment_post=true` **且** Cookie 含 `bili_jct` |

## 坑（都是真踩过的）

1. **清单为空 ≠ 插件坏了。** 匿名访问时平台常常不下发 AI 字幕。工具会明说是
   「匿名环境下平台未下发」，看到这句话就去配 Cookie，不要反复重试。
2. **不要用短链。** `b23.tv/xxx` 会被明确拒绝 —— 短链要先跟随跳转才能拿到 BV 号，
   插件不发这类隐式请求。把完整链接（含 `/video/BV…`）或 BV 号给过来。
3. **BV 号大小写敏感。** `BV17x411w7KC` 与 `BV17X411W7KC` 是两个不同的编号。
   复制时别手改大小写。
4. **`cid` ≠ 分P序号。** `cid` 是一串大整数，从 `bilibili_video` 的分P清单里取。
5. **翻页有上限，别指望"把所有评论都拉下来"。** 硬上限 10 页 / 每页 100 条，
   且页间默认有 150ms 节流（配置 `page_delay_ms`）。想看更多请缩小范围
   （按热度看前几页通常就够）。时间预算耗尽时，**已经取到的部分会照常返回**
   并注明停在第几页 —— 那是可用的部分结果，不是失败。
6. **-412 / -799 是风控，不是参数错误。** 报错信息里会明说。此时应降频、
   减少翻页，或配 Cookie；反复重试只会更糟。
7. **接口失败会带状态码与平台原话报错，不会给空列表。** 所以「报错」和
   「真的没有评论」是两件事 —— 不要看到报错就编一个结论。

## 用完可释放

```
plugin_stop  name=bilibili
```

## ★ 用 plugin_stop / plugin_start，不要用 plugin_disable / plugin_enable

四个工具看着像同义词，语义差别很大：

| 工具 | 作用 | 跨重启 |
|---|---|---|
| `plugin_stop` | **运行态**关闭，现在停掉 | **不影响**，重启照常加载 |
| `plugin_start` | **运行态**拉起，现在开回来 | 不影响 |
| `plugin_disable` | **持久**禁用 | **会记下来**，开机也不自启 |
| `plugin_enable` | 解除持久禁用 | 会记下来 |

**释放上下文用 `plugin_stop`。** 用 `plugin_disable` 会顺手把"开机自启"
永久关掉 —— 用户下次开机发现插件没了，得再手动开回来。

（本插件声明 `auto_start: false`，所以它本来就不自启；但 `plugin_disable`
仍会写进持久禁用清单，让 `plugin_start` 拒绝拉起，只能再用 `plugin_enable` 解。）
